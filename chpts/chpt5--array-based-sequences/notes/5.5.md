# 5.5 Using Array-Based Sequences
## 5.5.1 Storing High Scores for a Game
- Storing a sequence of high score entries for a video game:
    - First--consider what information to include in an object representing a high score entry
        1. An integer representing the score itself -> `_score`
        2. Name of person who earned the score -> `_name`
        
        Sample Code for Such a Class:
        ```Python
        class GameEntry:
            """Represents one entry of a list of high scores"""

            def __init__(self, name, score):
                self._name = name
                self._score = score
            
            def get_name(self):
                return self._name
            
            def get_score(self):
                return self._score:
            
            def __str__(self):
                return f"({self._name}, {self._score})
        ```
    - **A Class for High Scores**:
        - To maintain a sequence of high scores -> create a `ScoreBoard` class
            - Limited to a certain number of high scores that can be saved, once that limit is reached, a new score only qualifies for the scoreboard if it is strictly higher than the lowest curr high score
            - Internally, use a Python `list` named `_board` to manage the `GameEntry` instances that represent the high scores
            
            Code for such a class:
            ```python
            class ScoreBoard:
                """Fixed-length sequence of high scores in non decreasing order"""

                def __init__(self, capacity=10):
                    # init board with cap but all null entries
                    self._board = [None] * capacity

                    # n = actual entries
                    self._n = 0

                def __getitem__(self, k):
                    """Return an entry at index k"""
                    return self._board[k]
                

                def __str__(self):
                    """Return string representation of the high score list"""

                    return '\n'.join(str(self._board[i]) for i in range(self._n))
                
                def add(self, entry):
                    """Consider adding entry to high scores"""
                    score = entry.get_score()
                    
                    # can add is true if there is still space on board or if entry > last entry on board
                    need_add = (self._n < len(self._board)) or (score > self._board[-1].get_score())

                    if need_add:
                        # if there is still space
                        if self._n < len(self._board):
                            self._n += 1
                        
                        # use the smallest val--self._board[j]--to replace the score to add
                        # keep comparing j bottom up until reach when score to add is at the right place then j is at that place and replace j with score after loop exits
                        j = self._n - 1

                        while j > 0 and self._board[j-1].get_score() < score:
                            self._board[j] = self._board[j-1]
                            j -= 1
                        self._board[j] = entry
                    else:
                        return f"Score does not beat any of the top scores on the board"
            ```
        - **Adding an Entry**:
            - The `add()` method logic -> 
                - First check if needs to be added, it needs to be added if there is still space on the board or if the entry's score tops a current score
                - Then if needs to be added -> `need_add == True`
                    - Check to see which case it is
                        1. There is still enough space -> expand `self._n` which tracks the num of actual entries on board
                        2. The entry tops another score -> dive into replacement logic below
                    - **Replacement Logic**: Start at the bottom of the board (since this will be the score to be dropped), use this score as a "pointer" to traverse the score board--move this score up the score board--until the score above the "pointer" is no longer smaller than the new entry's score, at this point, we replace the "pointer" which contained the lowest score on the board with the entry!

## 5.5.2 Sorting a Sequence
- **The Insertion-Sort Algorithm**:
    1. Start with the first element of the array -> this is trivially sorted
    2. Then consider the next elt of the array
        - If it is smaller than the first -> swap them
        - Else: leave as is
    3. Then consider the third elt -> swap it lefward until it is in proper order with the first two elts
    4. ...Repeat step 3 until end of array

    High-level Pseudo-Code for `InsertionSort()`:
    ```
    Algorithm InsertionSort(A):
        Input: An array A of n comparable elts
        Output: The array A with elts rearranged in non-decreasing order

        for k from 1 to n - 1 do:
            Insert A[k] at its proper location within A[0], A[1], ..., A[k].
    ```
    - **Runtime**: Worst Case $O(n^2)$ if the array is initially in reverse order with the inner loop of moving an elt forward running $O(n)$ time occurring on every iteration of the outer loop $O(n)$ in traversing every elt
    ```Python
    def insertion_sort(A):
        """Sort list of comparable elts into nondecreasing order"""
        # Starting range at 1 since elt A[0] is trivially sorted
        for k in range(1, len(A)):
            curr = A[k]
            j = k

            # if curr elt is smaller than a previous -> move it up (via swap)
            while j > 0 and curr < A[j - 1]:
                A[j] = A[j - 1]
                j -= 1
            # once we found a spot where no elts to the left is greater than curr -> time to add curr
            A[j] = curr
        return A
    ```

## 5.5.3 Simple Cryptography
- An interesting application of `strings` and `lists` is **cryptography**--including ways of performing **encryption** (takes a message aka **plaintext** and converts it into a scrambled msg called **ciphertext**)
    - The earliest encryption scheme is the **Caesar cipher**--used by Caesar to protect important military msgs
        - The method of encryption was to replace every letter with a latter letter--i.e. A with D, B with E, ...

- **Converting Between Strings and Character Lists**:
    - Since strings are immutable:
        1. Convert string to list: `list(str)`
        2. Edit the list: `['s', 't', 'r']`
        3. Join the list back to str: `"".join(str_list)`

- **Using Characters as Array Indices**:
    - If we were to number the indices--A = 0, B = 1, ...
    - Then can apply **Caesar's Cipher** via $replacement = (idx + displacement) \mod{26}$
        - As a result, decipher algo -> $original = (idx - displacement) \mod{26}$

Code fo `CaesarCipher()`
```Python
class CaesarCipher:
    """Class for doing encryption and decryption using a Caesar Cipher"""

    def __init__(self, shift):
        """Construct Caesar cipher using given int shift for rotation"""
        encoder = [None] * 26
        decoder = [None] * 26

        for k in range(26):
            encoder[k] = chr((k + shift) % 26 + ord("A"))
            decoder[k] = chr((k - shift) % 26 + ord("A"))
        
        self._forward = "".join(encoder)
        self._backward = "".join(decoder)

    def encrypt(self, msg):
        """return string representing encrypted msg"""
        return self._transform(msg, self._forward)
    
    def decrypt(self, msg):
        """Return string representing decrypted msg"""
        return self._transform(msg, self._backward)
    
    def _transform(self, original, code):
        """Utility to perform transformation based on given code str"""
        msg = list(original)

        for k in range(len(msg)):
            if msg[k].isupper():
                # get the 0-25 val then use this to get the right char for encryption / decryption in given 'code' sequence
                j = ord(msg[k]) - ord("A")
                msg[k] = code[j]
        return "".join(msg)

    if __name__ == "__main__":
        # shift if 3
        cipher = CaesarCipher(3)
        message = "HELLO WORLD"
        coded = cipher.encrypt(message)
        print("encoded: ", coded)
        decoded = cipher.decrypt(coded)
        print("decoded: ", decoded)
```
