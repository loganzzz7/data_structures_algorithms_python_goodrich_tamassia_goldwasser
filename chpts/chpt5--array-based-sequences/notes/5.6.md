# 5.6 Multidimensional Data Sets
- `Lists`, `tuples`, `strings` in Python are one-dimensional--we use a single index to access each elt of the sequence
    - multi-dim -> i.e. img or geographical coords
    - 2D-array aka **matrix**
        - This is usually represented via a list of lists -> `A = [[], [], ...]`
        - This then can be accessed via `A[1][2]`--elt at idx 2 of the array at idx 1 in `A`

- **Constructing a Multidimensional List**:
    - To init a 1-D list: `A = [0] * n`--creates a list of $n$ zeros
    - **CANNOT** do `B = ([0] * c) * r` to create a 2D array! 
        - Since `[2, 4, 6] * 2 = [2, 4, 6, 2, 4, 6]`
    - This is **ALSO** a **MISTAKE** `B = [[0] * c] * r`
    - **CORRECT METHOD**: 
        - `[[0] * c for _ in range(r)]`

- **Two-Dimensional Arrays and Positional Games**:
    - **Tic-Tac-Toe**
        - Using two-dim board for game space 
        - Game board:\
        `[['O', 'X', 'O'], [' ', 'X', ' '], [' ', 'O', 'X']]`
    
    - Implementation of **Tic-Tac-Toe** in Python--public interface:
    ```Python
    game = TicTacToe()

    # X moves:             # O moves:
    game.mark(1, 1);       game.mark(0, 2)
    game.mark(2, 2);       game.mark(0, 0)
    game.mark(0, 1);       game.mark(2, 1)
    game.mark(1, 2);       game.mark(1, 0)
    game.mark(2, 0)

    print(game)
    winner = game.winner()

    if winner is None:
        print('Tie')
    else:
        print(winner, 'wins')
    ```

    - `mark(i, j)` adds a mark at the given coord for the player and the player just alternates
