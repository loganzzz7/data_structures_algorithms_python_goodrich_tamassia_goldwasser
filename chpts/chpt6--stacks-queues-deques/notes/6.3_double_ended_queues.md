# 6.3 Double-Ended Queues
- A data structure that supports insertion and deletion at both the front and back of the queue -> aka `Double-Ended Queue` or `deque`

## 6.3.1 The Deque Abstract Data Type
- The `deque` ADT is defined to support the following methods:
    1. `D.add_first(e)`: Add elt `e` to the front of the deque `D`
    2. `D.add_last(e)`: Add elt `e` to the back of deque `D`
    3. `D.delete_first()`: Remove and return the first elt from the deque `D`; an error occurs if `D` is empty
    4. `D.delete_last()`: Remove and return the last elt from the deque `D`; error if `D` is empty
    - Additionally, the following accessors:
        1. `D.first()`: Return but not remove the first elt of `D`; error if empty
        2. `D.last()`: Return but not remove the last elt of `D`; error if empty
        3. `D.is_empty()`: Return True if empty else False
        4. `len(D)`: Return the num of elts in `D`; implemented via the special func `__len__`

## 6.3.2 Implementing a Deque with a Circular Array
- A `deque` can be implemented the same way as the `ArrayQueue` class via a circular array

## 6.3.3 Deques in the Python Collections Module
- An implementation of a `deque` is available in Python's `collections` module -> `from collections import deque`
    - **Methods comparison**:
```
Our Deque ADT       collections.deque       desc
len(D)              len(D)                  num of elts
D.add_first()       D.appendleft()          add to start
D.add_last()        D.append()              add to end
D.delete_first()    D.popleft()             remove from start
D.delete_last()     D.pop()                 remove from end
D.first()           D[0]                    access first elt
D.last()            D[-1]                   access last elt
                    D[j]                    access j-th idx
                    D[j] = val              set j-th idx to val
                    D.clear()               clear all contents
                    D.rotate(k)             circularly shift right k steps
                    D.remove(e)             remove first matching elt e
                    D.count(e)              count num of matches for e
```
