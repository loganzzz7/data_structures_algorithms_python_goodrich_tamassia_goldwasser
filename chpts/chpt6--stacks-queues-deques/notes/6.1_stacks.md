# 6.1 Stacks
- A `stack` is a collection of objs that are inserted and removed according to the **last-in, first-out (LIFO)** principle.
    - A user can only access or rmv the most recently inserted obj that is at the "top" of the stack

## 6.1.1 The Stack Abstract Data Type
- **Definition**:
    - A `stack` is an abstract data type (ADT) s.t. an instance `S` supports the following two methods:
        1. `S.push(e)`: Add elt `e` to the top of the stack `S`
        2. `S.pop()`: Remove and return the top elt from the stack `S`; an error occurs if the stack is empty
    - Additionally, defining the accessor methods for convenience:
        1. `S.top()`: Return a reference to the top elt of stack `S` without removing it; an error occurs if the stack is empty
        2. `S.is_empty()`: Return `True` if stack `S` does no contain any elts
        3. `len(S)`: Return the number of elts in stack `S`; implemented via the special method `__len__`

## 6.1.2. Simple Array-Based Stack Implementation
- Can implement a stack via storing its elts in a Python `list`
    - The `list` class alr supports adding an elt to the end via the `append()` method and removing the last elt with the `pop()` method
- **The Adapter Pattern**:
```
Stack Method            Via Python List
S.push(e)               L.append(e)
S.pop()                 L.pop()
S.top()                 L[-1]
S.is_empty()            len(L) == 0
len(S)                  len(L)
```
- **Implementing a Stack Using a Python List**:
    - Use the adapter design pattern defined above to define an `ArrayStack` class that uses an underlying Python list for storage.
    ```Python
    class ArrayStack:
        """LIFO Stack implementation using a Python list as underlying storage"""
        def __init__(self):
            """Create an empty stack"""
            self._data = []
        
        def __len__(self):
            """Return the number of elts in the stack"""
            return len(self._data)
        
        def is_empty(self):
            """Return True if empty"""
            return True if len(self._data) == 0 else False
        
        def push(self, e):
            """Add elt e to the top of the stack"""
            self._data.append(e)
        
        def top(self):
            """Return (but do not remove) the elt at the top of the stack

            Raise Empty exception if the stack is empty
            """
            if self.is_empty():
                raise Empty("Stack is empty")
            return self._data[-1]

        def pop(self):
            """Remove and return the elt from the top of the stack (LIFO)

            Raise Empty exception if the stack is empty
            """
            if self.is_empty():
                raise Empty("Stack is empty")
            return self._data.pop()
    ```
- **Analyzing the Array-Based Stack Implementation**:
```
Operation           Running Time
S.push(e)           O(1)*
S.pop()             O(1)*
S.top()             O(1)
S.is_empty()        O(1)
len(S)              O(1)
* = amortized
```

## 6.1.3 Reversing Data Using a Stack
- Since stack is LIFO -> can be used as a general tool to reverse a data sequence
    - i.e. If the values 1, 2, 3 are pushed onto a stack -> when popped the order is 3, 2, 1 == reversed sequence!
    - i.e. Print lines of a file in reverse order in order to display a data set in decreasing order rather than increasing order -> reading each line and pushing it onto a stack then writing the lines in the order they are popped
    ```Python
    def reverse_file(filename):
        """Overwrite given file with its contents line-by-line reversed"""
        S = ArrayStack()
        original = open(filename)
        for line in original:
            S.push(line.rstrip('\n'))
        original.close()

        # now overwrite the contents in LIFO order
        output = open(filename, 'w')
        # while stack still has lines
        while not S.is_empty():
            output.write(S.pop() + '\n') # re-insert newline chars
        output.close()
    ```

## 6.1.4 Matching Parentheses and HTML Tags
- An Algorithm for Matching Delimiters:
```Python
def is_matched(expr):
    """Return True if all delimiters are properly matched; False otherwise"""
    left = '({['
    right = ']})'
    S = ArrayStack()

    for c in expr:
        if c in left:
            S.push(c)
        elif c in right:
            if S.is_empty():
                return False
            if right.index(c) != left.index(S.pop()):
                return False

    # at last True only if all matched else False
    return True if S.is_empty() else False
```
- Same logic can be used to match html opening and closing tags! to validate html code
