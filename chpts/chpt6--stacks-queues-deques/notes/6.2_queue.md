# 6.2 Queues
- Another fundamental data structure is the `queue`
    - Inserted and removed according to the `first-in, first-out (FIFO)` principle

## 6.2.1 The Queue Abstract Data Type
- Formally, the queue abstract data type defines a collection that keeps objects in a sequence, where elt access and deletion are restricted to the `first` elt in the sequence.
    - This enforces the rule that items are inserted and deleted in a queue according to `FIFO`
    - The `queue` ADT supports the following two fundamental methods for a queue Q:
        1. `Q.enqueue(e)`: Add elt `e` to the back of queue `Q`
        2. `Q.dequeue()`: Remove and return the first elt from queue `Q`; an error occurs if queue is empty
        - Also the following supporting methods:
            1. `Q.first()`: Return a reference to the elt at the front of queue `Q`, without removing it; an error occurs if the queue is empty
            2. `Q.is_empty()`: Return True if queue `Q` does not contain any elts
            3. `len(Q)`: Return the number of elts in a queue `Q`; implemented via special method `__len__`

## 6.2.2 Array-Based Queue Implementation
- A similar approach to the stack ADT is not the best approach since using `pop(0)` to remove the first elt of the list is inefficient as a call to `pop(0)` means a shift of all elts beyond the `0` idx to the left -> therefore resulting in $\Omega(n)$ time
    - So need to avoid using the call to `pop(0)` entirely
        - Replace the dequeued entry in the array with a ref to `None` and maintain an explicit var `f` to store the index of the elt that is currently at the front of the queue -> $O(1)$ time
            - But with this method, the underlying array structure would grow to be $O(m)$ and inefficient -> therefore need another revision
    - **Using an Array Circularly**:
        - Allow the front of the queue to drift rightward -> allow the contents of the queue to "wrap around" the end of an underlying array
        - Assume the underlying array has fixed len `N` that is greater than the actual num of elts in the queue -> new elts are enqueued towards the "end" of the current queue -> progressing from the front -> index `N - 1` and then -> index `0` -> `1`
            - When enqueue -> use arithmetic $f = (f + 1) \mod(N)$ -> modulo performs the "wrap around" when idx is gtr than $N$!

**Python Queue Implementation**:
- Internally, the queue class maintains the following 3 instance vars:
    1. `_data`: is a reference to a `list` instance with a fixed capacity
    2. `_size`: is an integer representing the curr num of elts stored in the queue (as opposed to the len of the `_data` obj)
    3. `_front`: is an integer that represents the index within `_data` of the first elt of the queue (given non empty queue)
    - Idea: initially reserve a list of moderate size for storing data--init `_front` to zero
        - When `front` or `dequeue`are called with no elts in the queue -> raise an instance of the `Empty` exception!
```Python
class ArrayQueue:
    """FIFO queue implementation using a Python list as underlying storage"""
    DEFAULT_CAPACITY = 10 # underlying array capacity

    def __init__(self):
        """Create an empty queue"""
        self._data = [None] * ArrayQueue.DEFAULT_CAPACITY
        # _size and _front refer to the "queue" adt and not underlying _data array
        self._size = 0
        self._front = 0
    
    def __len__(self):
        """Return the num of elts in Queue"""
        return self._size
    
    def is_empty(self):
        """Return True if empty"""
        return True if self._size == 0 else False

    def first(self):
        """Return (but do not remove) the elt at the front of the queue

        Raise Empty exception if the queue is empty
        """
        if self.is_empty():
            raise Empty("Queue is empty")
        else:
            return self._data[self._front]
        
    def dequeue(self):
        """Remove and return the first elt of the queue (FIFO)

        Raise Empty exception if the queue is empty
        """
        if self.is_empty():
            raise Empty("Queue is empty")
        
        answer = self._data[self._front]
        # after removing front -> replace with None
        self._data[self._front] = None
        # re-calc _front idx after removing via mod to "wrap around"
        self._front = (self._front + 1) % len(self._data)
        self._size -= 1
        return answer
    
    def enqueue(self, e):
        """Add an elt e to the back of the queue"""
        # if adding the elt exceeds underlying array size
        if self._size == len(self.data):
            # then double the array size
            self._resize(2 * len(self._data))
        avail = (self._front + self._size) % len(self._data)
        self._data[avail] = e
        self._size += 1
    
    def _resize(self, cap):
        """Resize to a new list of capacity >= len(self)"""
        old = self._data
        self._data = [None] * cap
        walk = self._front

        for k in range(self._size):
            self._data[k] = old[walk]
            walk = (1 + walk) % len(old)
        
        self._front = 0
```

**Implementation Runtimes**:
```
Operation           Running Time
--------------------------------
Q.enqueue(e)        O(1)*
Q.dequeue()         O(1)*
Q.first             O(1)
Q.is_empty()        O(1)
len(Q)              O(1)

* = amortized
```
