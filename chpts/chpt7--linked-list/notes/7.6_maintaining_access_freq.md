# 7.6 Case Study: Maintaining Access Frequencies
Consider maintaining a collection of elts while keeping track of the number of times each elt is accessed. Keeping such counts gives a metric on what is the most popular.
- `favorites list ADT`--supports `len` and `is_empty` methods as well as:
    1. `access(e)`: Access the element `e`, incrementing its access count, and adding it to the favorites list if it is not already present
    2. `remove(e)`: Remove elt `e` from the favorites list, if present
    3. `top(k)`: Return an iteration of the `k` most frequently accessed elts

## 7.6.1 Using a Sorted List
First approach for managing a favorites list:
- Store elts in a linked list, keeping them in nonincreasing order of access counts.
    - Access or remove an elt by searching the list from the most frequently accessed to the least frequently accessed. Reporting the top `k` most accessed elts -> the first `k` entries of the list
- Maintain the invariant: `elements are stored in nonincreasing order of access counts` -> must consider how a single access operation may affect the order.
    - When an access count changes, reestablish the invariant via a single pass of the `insertion-sort` algorithm

**Using the Composition Pattern**:
- Want to: implement a favorites list by making use of a `PositionalList` for storage!
    - Use a general object-oriented design pattern--the `composition pattern`, in which we define a single object that is composed of two or more other objects
        - Specifically, define a nonpublic nested class, `_Item`--that stores the elt and its access count as a single instance
            - Then maintain the favorites list as a `PositionalList` of `item` instances
            - This allows for account count for an elt to be embedded along it

```python
class FavoritesList:
    """List of elts ordered from most frequently accessed to lease"""

    #----- nested _Item class -----
    class _Item:
        __slots__ = "_value", "_count"

        def __init__(self, e):
            # element
            self._value = e
            # access count
            self._count = 0
        
    #----- nonpublic utilities -----
    def _find_position(self, e):
        """Search for element e and return its Position (or None if not found)"""
        walk = self._data.first()

        # move it down till 
        while walk is not None and walk.element()._value != e:
            walk = self._data.after(walk)
        return walk
    
    def _move_up(self, p):
        """Move item at Position p earlier in the list based on access count"""
        if p != self._data.first():
            cnt = p.element()._count
            walk = self._data.before(p)

            # shift forward if count higher
            if cnt > walk.element()._count:
                while (walk != self._data.first() and 
                        cnt > self._data.before(walk).element()._count):
                    walk = self._data.before(walk)
                self._data.add_before(walk, self._data.delete(p)) # delete / re-insert
    
    #----- public methods -----
    def __init__(self):
        """Create an empty list of favorites"""
        self._data = PositionalList() # a list of `_Item` instances
    
    def __len__(self):
        """Return number of entries on favorites list"""
        return len(self._data)
    
    def is_empty(self):
        """Return True if list is empty"""
        return len(self._data) == 0
    
    def access(self, e):
        """Access element e, thereby increasing access count"""
        # try to locate element in list
        p = self._find_position(e)
        
        if p is None:
            # new then place at end
            p = self._data.add_last(self._Item(e))

        p.element()._count += 1

        self._move_up(p)
    
    def remove(self, e):
        """Remove elt e from this list of favorites"""
        p = self._find_position(e)
        if p is not None:
            self._data.delete(p)
        
    def top(self, k):
        """Generate a sequence of to k elts in terms of access count"""
        if not 1 <= k <= len(self):
            raise ValueError("Illegal k value")

        walk = self._data.first()

        for _ in range(k):
            item = walk.element()
            yield item._value
            # iterate
            walk = self._data.after(walk)
```

## 7.6.2 Using a List with the Move-to-Front Heuristic
The previous implementation of a favorties list performs the `access(e)` method in time proportional to the index of `e` in the favorites list.
- If `e` is the $k^{th}$ most popular elt of the favs list, then accessing it takes $O(k)$ time!
    - Once an elt is accessed it is more likely to be accessed again in the near future--`locality of reference`
    - A `heuristic` which takes advantage of the locality of reference that exists in an access sequence is:
        - **Move-to-front-heuristic**

**Move-to-front-heuristic**:
- To apply this heuristic:
    - Each time we access an elt, move it all the way to the front of the list, hoping that this elt is accessed again soon in the future

**The Trade-Offs with the Move-to-Front Heuristic**:
- If we no longer maintain the elts of the favs list ordered by their access counts, when we are asked to find the k most accessed elts, we need to search for them
    - This requires a reimplementation of the `top(k)` method:
        1. Copy all entries of our favs list into another list, named `temp`
        2. Scan the `temp` list `k` times, in each scan, find entry with largest access count, remove this entry from `temp` and report it
    - This takes $O(kn)$ time, when `k` is a constant, it is $O(n)$ time. However if `k` is eq to `n` then it will be $O(n^2)$ time

**Implementing the Move-to-Front Heuristic in Python**:
```python
class FavoritesListMTF(FavoritesList):
    """List of elts ordered with move-to-front heuristic"""

    # we override _move_up to provide move-to-front semantics
    def _move_up(self, p):
        """Move accessed item at Position p to front of list"""
        if p != self._data.first():
            # delete / insert
            self._data.add_first(self._data.delete(p))

    # we override top before list is no longer sorted
    def top(self, k):
        """Generate sequence of top k elts in terms of access count"""
        if not 1 <= k <= len(self):
            raise ValueError("Illegal k value")
        
        # we begin by making a copy of the original list
        temp = PositionalList()
        for item in self._data:
            temp.add_last(item)
        
        # we repeatedly find, report, and remove elt with largest count
        for j in range(k):
            # find and report next highest from temp
            highPos = temp.first()
            walk = temp.after(highPos)

            while walk is not None:
                if walk.element()._count > highPos.element()._count:
                    highPos = walk
                walk = temp.after(walk)
            
            # we have found the elt w the highest count
            # report elt to the user
            yield highPos.element()._value
            # remove from temp list
            temp.delete(highPos)
```
