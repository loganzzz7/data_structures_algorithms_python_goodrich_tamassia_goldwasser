# 7.1 Singly Linked Lists
- A `singly linked list` -> a collection of `nodes` that collectively form a linear sequence
    - Each node stores a reference to an objext that is an elt of the sequence as well as a reference to the next node of the list
    ```
    head -> (ptr to obj, next ptr) -> (ptr to obj, next ptr == None)--tail
    ```
    - The first and last node of a linked list are the `head` and `tail` of the list
        - Starting from `head`, move from 1 node to the next via the node's next ptr and eventually reaching `tail` aka `traversing` the linked list--the next reference of a node is a pointer to another node
    - In memory, each node is represented as an unique obj--storing a reference to its element and a reference to the next node (or `None` for tail)
        - At min: an instance of a linked list must keep a reference to the head of the list
            - Without it, it would be impossible to locate the first node and as a result, the rest of the list

**Inserting an Element at the Head of a Singly Linked List**:
- A linked list does not have a predetermined fixed size -> uses space proportionally to its current num of elts
    - When using a singly linked list -> can easily insert an elt at the head of the list
        - Process: create a new node, set its elt to the new elt, set its next link to refer to the current head, update head to point to the new node at the front
        ```Python
        Algorithm add_first(L, e):
            newest = Node(e)        # Create new node e
            newest.next = L.head    # Set new node's next ptr to the head
            L.head = newest         # Set the list's head to the new node
            L.size += 1             # Increment size tracking var
        ```

## Implementing a Stack with a Singly Linked List
- Implementation of the stack ADT via a singly linked list
    - Top of the stack = top of the linked list since we can efficiently insert and remove at the top and in a stack its LIFO
        - To represent each individual node -> following lightweight `_Node` class
        ```Python
        class _Node:
            """Lightweight, non public class for storing a singly linked node"""
            __slots__ = '_element', '_next'     # streamline memory usage -> efficent to remove __dict__ overhead when there will be many instances of this class

            def __init__(self, element, next):  # init the node
                self._element = element
                self._next = next
        ```
    - `push` is implemented via: `self._head = self._Node(e, self._head)` -> setting head of list to a new `_Node()` with the next ptr set to the curr head

```Python
class LinkedStack:
    """LIFO Stack implementation via a singly linked list"""

    class _Node:
        """Lightweight, non public class for storing a singly linked node"""
        __slots__ = '_element', '_next'     # streamline memory usage -> efficent to remove __dict__ overhead when there will be many instances of this class

        def __init__(self, element, next):  # init the node
            self._element = element
            self._next = next

    # Stack Methods
    def __init__(self):
        """Create an empty stack"""
        self._head = None
        self._size = 0

    def __len__(self):
        """Return len of LinkedStack"""
        return self._size

    def is_empty(self):
        """Return True if empty else False"""
        return True if self._size == 0 else False

    def push(self, e):
        """Push an elt onto the stack--append at head"""
        new = self._Node(e, self._head)
        self._head = new
        self._size += 1
    
    def top(self):
        """Return (but not remove) the top elt of the stack"""
        if self.is_empty():
            raise Empty("Empty Stack")
        return self._head._element

    def pop(self):
        """Remove and return the elt from the top of the stack"""
        if self.is_empty():
            raise Empty("Empty Stack")
        
        res = self._head._element
        self._head = self._head.next
        self._size -= 1

        return res
```


## 7.1.2 Implementing a Queue with a Singly Linked List
- Implementaion of the queue ADT while supporting $O(1)$ time for all operations via a singly linked list
    - Align the front of the linked list to the front of the queue -> need to `enqueue` elts at the back and `dequeue` from the front
```Python
class LinkedQueue:
    """FIFO queue implementation using a singly linked list for storage"""
    class _Node:
        __slots__ = "_element", "_next"

        def __init__(self, e, next):
            self._element = e
            self._next = next

    def __init__(self):
        """Create an empty queue"""
        self._head = None
        self._tail = None
        self._size = 0
    
    def __len__(self):
        return self._size

    def is_empty(self):
        return True if self._size == 0 else False
    
    def first(self):
        """Return (but do not remove) the elt at the front of the queue"""
        if self.is_empty():
            raise Empty("Empty Queue")
        return self._head._element
    
    def dequeue(self):
        """Remove and return the first element of the queue (i.e. FIFO)

        Raise Empty exception if empty
        """
        if self.is_empty():
            raise Empty("Empty Queue")
        
        res = self._head._element
        self._head = self._head._next
        self._size -= 1

        if self.is_empty():
            self._tail = None
        return res
    
    def enqueue(self):

        if self.is_empty():
            # if empty then adding to back will be front
            self._head = newest
        else:
            # if not empty add to next of back
            self._tail._next = newest
        
        self._tail = newest
        self._size += 1
```
