# Circularly Linked Lists
- Remember the "circular" implementation of the `queue` ADT -> this is artificial as there was nothing in the representation of the array itself that was circular
    - However, for linked lists, it is possible to be circular in the sense that the tail of the list will have the next reference pointing back to the start of the list -> `circularly linked list`
        - Best used for data sets that are cyclic--no beginning / end
            - i.e. chicago loop train stops

## 7.2.1 Round-Robin Schedulers
- To motivate the use of a circularly linked list -> consider a **round-robin** scheduler, iterates through a collection of elts in a circular fashion
    - Use case: to fairly allocate a resource that must be shared by a collection of clients
        - i.e. round-robin scheduling is often used to allocate slives of CPU time to various applications running concurrently on a computer
    - **Implementation**:
        - General `queue` (FIFO) ADT, repeatedly performing the following steps on queue `Q`
            1. `e = Q.dequeue()`
            2. `Service element e`
            3. `Q.enqueue(e)`
            - So remove an elt `e` from the top of the queue, let it use the cpu, then add it to the back of the queue
- **Implementation of CircularQueue**:
    - Need to have an additional method `rotate()`--moves the first elt of the queue to the back
        - Also supported by a method in the `deque` class (`collections.deque`): `D.rotate(k)`
        - Via this operation, round-robin steps:
            1. Service element `Q.front()`
            2. `Q.rotate()`

## 7.2.2 Implementing a Queue with a Circularly Linked List
- Instance variables: `_tail` and `_size` -> `self._tail._next` == head of the queue
```Python
class CircularQueue:
    """Queue implementation using circularly linked list for storage"""
    
    class _Node:
        """Lightweight, nonpublic class for storing a singly linked node"""
        __slots__ = "_element", "_next"

        def __init__(self, e, next):
            self._element = e
            self._next = next
    
    def __init__(self):
        """Create an empty queue"""
        self._tail = None
        self._size = 0

    def __len__(self):
        """Return the num of elts in the queue"""
        return self._size
    
    def is_empty(self):
        return True if self._size == 0 else False
    
    def first(self):
        """Return (but do not remove) the first elt of the list"""
        if self.is_empty():
            raise Empty("Empty Queue Error")
        
        # head = self._tail._next
        return self._tail._next._element
    
    def dequeue(self):
        """Remove and return the first elt of the queue (FIFO)"""
        if self.is_empty():
            raise Empty("Empty Queue Error")
        
        oldhead = self._tail._next

        # removing the only elt (edge case)
        if self._size == 1:
            self._tail = None
        else:
            # there exists more than 1 elt (main)
            self._tail._next = oldhead._next
        self._size -= 1

        return oldhead._element

        def enqueue(self, e):
            """Add an elt to the back of queue"""
            newest = self._Node(e)

            if self.is_empty():
                # one elt -> self circular
                newest._next = newest
            else:
                # point newest's next to head for circular
                head = self._tail._next
                newest._next = head
            self._tail = newest
            self._size += 1
        
        def rotate(self):
            """Rotate front element to the back of the queue"""
            if self._size > 0:
                self._tail = self._tail._next
```
