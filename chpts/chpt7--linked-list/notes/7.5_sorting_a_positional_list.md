# 7.5 Sorting a Positional List
Perform `insertion-sort` on a `PositionalList`:
- Maintain a variable `marker` that represents the rightmost position of the currently sorted portion of a list
    - During each pass, consier the position just past the `marker` as the `pivot` and consider where the pivot's elt belongs relative to the sorted portion.
    - Then use another variable `walk` to move leftward from the marker, as long as there remains a preceding elt with the value larger than the pivot's

    ```Python
    def insertion_sort(L):
        """Sort PositionalList of comparable elts into nondecreasing order"""
        if len(L) > 1:
            marker = L.first()
            while marker != L.last():
                pivot = L.after(marker)
                value = pivot.element()
                
                if value > marker.element():
                    # pivot is alr in a sorted position so move marker
                    marker = pivot
                else:
                    walk = marker
                    while walk != L.first() and value < L.before(walk).element():
                        walk = L.before(walk)

                    # rmv pivot and put it in the right pos
                    L.delete(pivot)
                    # insert the pivot before walk
                    L.add_before(walk, value)
    ```
