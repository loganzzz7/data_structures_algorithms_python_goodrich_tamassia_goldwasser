# 8.4 Tree Traversal Algorithms
A **traversal** of a tree `T` is a systematic way of accessing, or "visiting," all the positions of `T`. The specific action associated with the "visit" of a position `p` depends on the application of this traversal, and could involve anything from incrementing a counter to performing some complex computation for p.

## 8.4.1 Preorder and Postorder Traversals of General Trees
**Preorder Traversal**:
- The root of `T` is visited first and then the subtrees rooted at its children are traversed recursively. If the tree is ordered, then the subtrees are traversed according to the order of the children. 
    - Order: `root -> left -> right`
```python
Algorithm preorder(T, p):
    perform the "visit" action for position p
    for each child c in T.children(p) do:
        preorder(T, c)          # Recursively traverse the subtree rooted at c
```

**Postorder Traversal**:
- "Opposite" of the preorder traversal, it recursively traverses the subtrees rooted at the children of the root first, and then visits the root (hence, "postorder"!!)
    - Order: `left -> right -> root`
```python
Algorithm postorder(T, p):
    for each child c in T.children(p) do:
        postorder(T, c)         # Recursively traverse the subtree rooted at c
    perform the "visit" action for position p
```

**Running-Time Analysis**:
- Non-recursive part of the traversal algorithm takes time $O(c_p + 1)$ where $c_p$ is the num of children of $p$, under the assumption that the "visit" itself takes $O(1)$ time.
    - Overall running time for the traversal of tree `T` is $O(n)$, where $n$ is the num of positions in the tree. This running time is asymptotically optimal since the traversal must visit all the $n$ positions of the tree.

## 8.4.2 Breadth-First Tree Traversal--BFS
Visit all the positions at depth $d$ before visiting the positions at depth $d + 1$--**breadth-first traversal**
- This is a common approach used in software for playing games. A **game tree** represents the possible choices of moves that might be made by a player (or computer) during a game, with the root of the tree being the initial configuration for the game.
    - i.e. Tic-Tac-Toe
    - A breadth-first traversal of such a game tree is often performed because a computer may be unable to explore a complete game tree in a limited amount of time. So the computer will consider all moves, then responses to those moves, going as deep as computational time allows.
- Pseudo-code: 
    - Non-recursive, since we are not traversing entire subtrees at once. Use a queue to produce a FIFO semantics for the order in which we visit nodes. $O(n)$ tunning time due to $n$ calls to `enqueue` and $n$ calls to `dequeue`.
    ```python
    Algorithm breadthfirst(T):
        init queue Q to contain T.root()
        while Q not empty do:
            p = Q.dequeue()
            perform the "visit" action for position p
            for each child c in T.children(p) do:
                Q.enqueue(c)
    ```
